# Code of Conduct

## Our Commitment

We are committed to making participation in this project a welcoming, respectful, inclusive, and harassment-free experience for everyone.

This Code of Conduct applies to all contributors, maintainers, users, and community members participating in this repository and its related project spaces.

We welcome contributions from people with different backgrounds, experience levels, perspectives, and skill sets.

---

## Expected Behavior

We expect all community members to:

* Be respectful and considerate toward others.
* Communicate constructively and professionally.
* Welcome different opinions and approaches.
* Give helpful and actionable feedback.
* Focus discussions on ideas, code, documentation, and technical decisions rather than individuals.
* Accept constructive criticism gracefully.
* Help maintain a friendly and collaborative environment.
* Respect project maintainers, contributors, and community members.
* Credit original work and respect licenses when contributing external resources.

---

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment, discrimination, or personal attacks.
* Threats, intimidation, or deliberate hostility.
* Trolling or intentionally disruptive behavior.
* Insults or degrading comments directed at individuals or groups.
* Sexual harassment or unwanted sexual content.
* Publishing someone's private or personal information without permission.
* Deliberately misleading, impersonating, or malicious behavior.
* Spam or excessive self-promotion unrelated to the project.
* Deliberately submitting malicious code, links, or other harmful content.
* Any other behavior that would reasonably make the project community unsafe or unwelcoming.

---

## Technical Discussions

Technical disagreements are normal and encouraged when they help improve the project.

When discussing implementation, architecture, SEO, 3D technologies, AI, WebGL, Three.js, React Three Fiber, performance, or other technical topics:

* Critique the technical approach, not the person.
* Provide reasoning or evidence where possible.
* Consider alternative solutions fairly.
* Keep discussions relevant to the project.
* Avoid turning technical disagreements into personal arguments.

Maintainers may close or redirect discussions that become unproductive or unrelated to the project.

---

## Contribution Standards

Contributors should make a reasonable effort to:

* Follow the repository's contribution guidelines.
* Provide accurate information.
* Avoid knowingly submitting broken or malicious resources.
* Respect the licenses of third-party content.
* Prefer official documentation and reliable sources when adding resources.
* Clearly identify significant changes when submitting pull requests.
* Respond respectfully to review feedback.

---

## Reporting Unacceptable Behavior

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers.

When reporting an issue, provide as much relevant information as you are comfortable sharing, such as:

* What happened.
* Where it happened.
* When it happened.
* Relevant links, issues, pull requests, or comments.
* Any additional context that may help the maintainers understand the situation.

Please avoid publicly sharing private or sensitive information.

For security vulnerabilities or malicious code, use the project's designated security reporting process rather than publicly discussing the vulnerability.

---

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Depending on the circumstances, maintainers may:

1. Ask participants to stop inappropriate behavior.
2. Remove comments or other content.
3. Close issues or discussions.
4. Restrict participation in project spaces.
5. Temporarily or permanently ban individuals from participating in the project.

Enforcement decisions will be made based on the circumstances and severity of the behavior.

---

## Scope

This Code of Conduct applies within:

* This GitHub repository.
* Issues and pull requests.
* Discussions and project-related communication channels.
* Other spaces where an individual is officially representing the project or community.

---

## Questions
